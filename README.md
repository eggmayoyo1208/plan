# TRIPLY 업데이트 사용법

1. 기존 프로젝트를 복사해 백업하세요.
2. 이 폴더의 `index.html`, `style.css`를 같은 위치에 두세요. 기존 HTML/CSS에 부분적으로 덧붙이는 파일이 아니라 교체용 통합본입니다. JavaScript는 HTML 마지막에 포함돼 있습니다.
3. 기존 `images` 폴더를 `index.html` 옆에 두세요. 원본 사진은 제공받지 못해 포함하지 않았습니다. 사진이 없어도 일정과 편집 기능은 사용할 수 있습니다.
4. `index.html`을 Live Server로 여세요. 이전 `budget.html`로 연결할 필요 없이 예산 카드를 누르면 같은 페이지 안에서 예산 현황이 열립니다.

## 조작

- 여행 카드: 가로 스와이프 또는 좌우 화살표. 끝의 + 카드에서 새 여행을 만듭니다. 여행별 일정·인원·예산은 독립적입니다.
- 파란 여행지: 국가/도시순 50개 기본 선택지 검색 또는 직접 입력. 통계에 근거한 인기 순위 목록은 아닙니다. 여행지만 바꿔도 기존 일정이 자동 생성되거나 바뀌지는 않습니다.
- 여행 날짜·인원·편집: 출발/종료 날짜, 인원, 총예산 수정. 여행은 최대 366일입니다. 기간을 줄일 때 삭제될 날짜에 일정이 있으면 먼저 이동/삭제해야 합니다.
- Day 끝의 +: 하루를 추가하고 종료일을 연장합니다. + 일정 추가: 현재 여행에 장소를 추가합니다.
- 카드: 배경이 흐려지는 편집창. 다른 Day로 일정 이동도 가능합니다.
- 왼쪽 시간 / 금액: 직접 수정. 저장 즉시 잔액, Day 합계, 예산 원그래프에 반영됩니다.
- 장소명 옆 작은 핀: 국가·도시·장소명으로 구글맵 검색을 새 탭에서 엽니다. 검증된 장소 ID가 아닌 검색 링크이므로 동명이인 장소는 지도에서 확인하세요.
- 사진: 썸네일 클릭 → 흐린 사진 위 + 및 ‘클릭하여 내 사진으로 교체’ 클릭 → 기기 사진 선택. 파일 선택 버튼으로도 가능합니다. 원본 복원 버튼은 사용자 사진만 제거합니다.
- ×: 해당 일정 삭제(확인창 표시).

## 저장 및 범위

일정과 사진은 localStorage에 이 브라우저의 사이트 주소별로 저장됩니다. 로그인/서버/클라우드 동기화는 없습니다. Live Server의 포트 또는 브라우저가 달라지면 별도 저장 공간을 사용합니다. 시크릿 모드나 사이트 데이터 삭제 시 사라질 수 있습니다. 저장 용량 초과나 차단 시 화면에 경고가 표시됩니다. 사진은 20MB까지 선택할 수 있고 저장 전에 최대 1200px JPEG로 줄여집니다. HEIC 등 브라우저가 읽지 못하는 형식은 JPG/PNG로 바꿔 선택하세요.

금액은 실제 결제/지출 기록이 아닌 원화 기준 예상 비용입니다. 원본 12개 일정의 합은 450,000원, 예산 800,000원 기준 잔액은 350,000원입니다. 이전 예산 화면의 고정 샘플 숫자/세부내역을 사용하지 않습니다.

기존 이미지 경로 및 12개 일정 정보는 유지했습니다. 이전의 메뉴 서랍·추천 동선 적용 버튼·일정 좌우 스와이프 제스처는 이번 통합본에 포함하지 않았습니다. 일정 수정/삭제는 카드 클릭 및 × 버튼으로 제공합니다. 새로운 Day에는 자동 추천 일정이 채워지지 않습니다. Pretendard가 설치되지 않은 기기에서는 시스템 폰트를 사용합니다.
